# C8 production conversion and stop evidence

C8 stages two production JSON definitions: ROCm FPX and Halogen. Both leaves
remain inactive. Halo Box, Nathanw and OCI DS4 stop on reproducible additional
format gaps; their attempted profiles remain test fixtures, never production
resources or execution grants. The active catalog still has seventeen recipes.

The original seven v1 definitions, both fixed v2 policies, `llamacpp@1`, Gufo,
all fourteen prior transition disclosures and their original readers stay
byte-identical. C8 replays them against a separately built C7b control and
independently discloses each new production inventory stage. Whole-snapshot
comparison is literal. No comparator exception is installed.

## C7b fixture boundary

C7b describes each source fixture as "an independently reviewed synthetic
definition, literal expected lines, its rewrite domain, and exact load/stream
quotations". Four fixtures contain Gufo's synthetic `serve llm` argv rather
than the corresponding engine's argv. The handoff's claim that all five freeze
exact production argv is therefore incorrect.

The source also says: "All five engines' identified C7/C7a data-contract
blockers are now expressible." C8 confirms those specific contracts but finds
additional gaps in the production source paths. The broader handoff claim that
there is no outstanding format blocker is contradicted by the three stop
reports. No runtime contract was widened to bypass those stops.

C8 preserves the original diagnostic records and compares complete ordered
rendered lines with production facts substituted for synthetic recipe/image/
custom-option facts. It checks valid and malformed rewrite bytes over ephemeral
loopback HTTP. Production argv, mounts, devices, readiness, metadata and model
inventory come from the separately pinned wrappers/headers and C6 fixtures.
All original C7b fixtures and quotations are unchanged.

## Independent dormant grants

`src/cpp/server/backends/configured/dormant_container_owners/`. CMake embeds
these literals through the existing 8,000-byte splitter. Authority is never
computed from the definition being authorized at build or runtime. The
accessor is used only in isolated parity catalogs. Hook removal retains the
execution owner and cannot admit a foreign repository or remove diagnostics.

## Activation

Both new leaves and Gufo need registry/image validation; actual container
networking, GPU selection, inference, cancellation and cleanup qualification;
packaging validation; a reviewed fixed active leaf/hook policy and executable
registration with mask zero; generator-produced active defaults/support; and a
new disclosed activation stage. CPU fake-host parity satisfies none of the real
runtime gates. Halo Box, Nathanw and OCI DS4 additionally need their documented
format prerequisites and then a complete production conversion/parity campaign.
